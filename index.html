Vision Transformer with ROI-Based Patch Fusion for OCT Classification
A ViT-based deep learning system detecting Diabetic Macular Edema from retinal OCT scans, outperforming CNN baselines on Kaggle and clinical datasets.
PyTorchViTMedical ImagingOCT
  • ROI-Based Patch Embedding Fusion: instead of uniform patch tokenisation, first applies a lightweight region-detection head to identify clinically relevant retinal regions (fluid-filled cysts, sub-retinal fluid, ellipsoid zone disruptions). ROI patches are encoded with higher embedding resolution — preserving micro-structural details that uniform patching loses.
  • Multi-level Feature Fusion: aggregates attention feature maps from multiple ViT encoder layers (early shallow features for texture, mid-level for contour, deep layers for semantic pathology) — similar in spirit to FPN but operating entirely within the transformer attention space.
  • PyTorch implementation with a custom collation function for variable-size ROI patches, mixed-precision training (torch.cuda.amp) for faster convergence, and a weighted cross-entropy loss accounting for class imbalance in the clinical dataset (DME vs. Normal vs. Drusen).
  • Outperformed ResNet-50 and standard ViT-B/16 baselines on two benchmarks — Kaggle OCT 2017 dataset and a proprietary clinical dataset — by ≈3.5% accuracy and ≈5% AUC-ROC through the ROI-aware patching strategy.
  • Validated interpretability via GradCAM++ overlays confirming the model attends to medically relevant regions, not spurious scan artefacts.
